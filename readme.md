# PoseNet Project

## 📌 About

PoseNet is a web-based project that uses pose detection to detect and track human body positions.

## ✨ Features

- Human pose detection
- Real-time pose tracking
- Interactive visual output
- Web-based application

## 🛠️ Technologies Used

- HTML
- JavaScript
- p5.js
- PoseNet
- ml5.js
